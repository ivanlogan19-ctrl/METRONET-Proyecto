## PostgreSQL ##

## Descripción ##

PostgreSQL es un sistema gestor de bases de datos relacional de código abierto.

## Función en METRONET ##

Almacena toda la información del sistema, incluyendo líneas, estaciones, trenes y configuraciones operativas.

## Ventajas ##

- Gratuito.
- Seguro.
- Escalable.
- Compatible con aplicaciones empresariales.
