## Java ## 

## Descripción ##

Java es el lenguaje principal utilizado para desarrollar el backend del proyecto METRONET.

## Función en METRONET ## 

Se utiliza para implementar la lógica de negocio, las reglas del sistema y los servicios que gestionan la información.

## Ventajas ## 

- Orientado a objetos.
- Amplio soporte empresarial.
- Gran comunidad.
- Compatible con Spring Boot.

## Uso en el proyecto ## 

El backend del proyecto fue desarrollado utilizando Java y Spring Boot.
