## Spring Boot ##

## Descripción

Spring Boot es un framework de Java que simplifica el desarrollo de aplicaciones web y APIs.

## Función en METRONET ##

Permite desarrollar el backend y exponer servicios REST para que el frontend pueda intercambiar información con la base de datos.

## Ventajas ##

- Desarrollo rápido.
- Configuración simplificada.
- Integración con PostgreSQL.
- Amplia adopción en la industria.

## Uso en el proyecto ##

Toda la API del sistema será implementada utilizando Spring Boot.
