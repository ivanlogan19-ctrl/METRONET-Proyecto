## Node.js ##

## Descripción ##

Node.js es un entorno de ejecución para JavaScript.

## Función en METRONET ##

Permite ejecutar herramientas necesarias para el desarrollo y funcionamiento del frontend.

## Ventajas ##

- Amplio ecosistema de paquetes.
- Fácil integración con tecnologías web modernas.

## Uso en el proyecto ##

Se utiliza para gestionar dependencias y ejecutar el frontend.
