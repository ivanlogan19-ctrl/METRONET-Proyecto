# Phaser

## Descripción

Phaser es un framework especializado en el desarrollo de videojuegos y simulaciones 2D.

## Función en METRONET

Permite representar gráficamente la red de metro, estaciones, conexiones y movimientos de trenes.

## Ventajas

- Renderizado eficiente.
- Fácil manejo de escenas.
- Ideal para simulaciones interactivas.

## Uso en el proyecto

Será la tecnología principal utilizada para construir la interfaz gráfica de la simulación.
