# Ramas del Proyecto

## Objetivo

Este documento describe la estructura de ramas utilizada en METRONET y las responsabilidades asociadas a cada una.

---

# Estructura de Ramas

```text
main
│
├── integracion-equipo
│
├── desarrollo-logan
├── desarrollo-juan
└── desarrollo-viviana
```

---

# Rama Main

La rama main contiene la versión estable y oficial del proyecto.

Ningún integrante deberá trabajar directamente sobre esta rama.

Solo el administrador del proyecto podrá integrar cambios en main.

---

# Rama Integracion-Equipo

La rama integracion-equipo se utiliza para unificar los desarrollos realizados por los integrantes del equipo.

Los cambios son revisados antes de ser incorporados a main.

Solo el administrador del proyecto podrá integrar cambios en esta rama.
