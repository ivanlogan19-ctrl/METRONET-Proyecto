# Comandos Básicos de Git

## Verificar Estado

```bash
git status
```

Muestra el estado actual del repositorio.

---

## Descargar Cambios

```bash
git pull
```

Actualiza la rama local.

---

## Agregar Cambios

```bash
git add .
```

Agrega todos los cambios al área de preparación.

---

## Crear Commit

```bash
git commit -m "Descripción del cambio"
```

Guarda los cambios localmente.

---

## Subir Cambios

```bash
git push
```

Envía los cambios al repositorio remoto.

---

## Ver Rama Actual

```bash
git branch
```

Muestra la rama activa.
