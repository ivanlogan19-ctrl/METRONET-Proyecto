# Qué Instalar

## Objetivo

Antes de comenzar a trabajar en el proyecto METRONET, todos los integrantes del equipo deberán instalar las herramientas descritas en este documento.

Cada una cumple una función específica dentro del desarrollo del proyecto.

---

# Git

## ¿Qué es?

Git es un sistema de control de versiones.

## ¿Para qué se utiliza?

Permite registrar cambios en el proyecto y trabajar en equipo sin sobrescribir el trabajo de otros integrantes.

## Sitio oficial

https://git-scm.com

---

# Visual Studio Code

## ¿Qué es?

Visual Studio Code es un editor de código fuente.

## ¿Para qué se utiliza?

Permite editar código, documentación y archivos de configuración del proyecto.

## Sitio oficial

https://code.visualstudio.com

---

# Java 17

## ¿Qué es?

Java es un lenguaje de programación orientado a objetos.

## ¿Para qué se utiliza?

Es la tecnología utilizada para desarrollar el backend del proyecto mediante Spring Boot.

## Sitio oficial

https://adoptium.net

---

# Maven

## ¿Qué es?

Maven es una herramienta de gestión de proyectos para Java.

## ¿Para qué se utiliza?

Permite compilar, ejecutar y administrar las dependencias del backend.

## Sitio oficial

https://maven.apache.org

---

# PostgreSQL

## ¿Qué es?

PostgreSQL es un sistema gestor de bases de datos relacional.

## ¿Para qué se utiliza?

Almacena toda la información del proyecto, incluyendo estaciones, líneas, conexiones y demás datos necesarios para la simulación.

## Sitio oficial

https://www.postgresql.org

---

# DBeaver

## ¿Qué es?

DBeaver es una herramienta gráfica para administrar bases de datos.

## ¿Para qué se utiliza?

Facilita la visualización, consulta y mantenimiento de la base de datos PostgreSQL.

## Sitio oficial

https://dbeaver.io

---

# Node.js

## ¿Qué es?

Node.js es un entorno de ejecución para JavaScript.

## ¿Para qué se utiliza?

Permite ejecutar y administrar las dependencias necesarias para el frontend del proyecto.

## Sitio oficial

https://nodejs.org

---

# IntelliJ IDEA Community Edition (Opcional)

## ¿Qué es?

Entorno de desarrollo integrado especializado en Java.

## ¿Para qué se utiliza?

Facilita el desarrollo y depuración del backend.

## Sitio oficial

https://www.jetbrains.com/idea

---

# GitHub Desktop (Opcional)

## ¿Qué es?

Aplicación gráfica para trabajar con Git y GitHub.

## ¿Para qué se utiliza?

Permite realizar operaciones básicas de Git sin utilizar la terminal.

## Sitio oficial

https://desktop.github.com

---

# Resumen

Para trabajar correctamente en METRONET es obligatorio contar con:

* Git
* Visual Studio Code
* Java 17
* Maven
* PostgreSQL
* DBeaver
* Node.js

Las herramientas IntelliJ IDEA Community Edition y GitHub Desktop son opcionales pero recomendadas.
