# Cómo Instalar las Herramientas Necesarias

## Objetivo

Este documento explica paso a paso cómo instalar todas las herramientas necesarias para trabajar en el proyecto METRONET.

---

# Git

## Windows

1. Ingresar a:

https://git-scm.com/download/win

2. Descargar el instalador.

3. Ejecutar el archivo descargado.

4. Mantener todas las opciones por defecto.

5. Finalizar la instalación.

---

## macOS

1. Abrir la aplicación Terminal.

2. Ejecutar:

```bash
git --version
```

3. Si Git no está instalado, macOS ofrecerá instalar las herramientas necesarias.

4. Completar la instalación.

---

# Maven

## Windows

1. Descargar desde:

https://maven.apache.org/download.cgi

2. Descomprimir el archivo.

3. Configurar la variable de entorno PATH.

4. Reiniciar la terminal.

---

## macOS

Si se utiliza Homebrew:

```bash
brew install maven
```

---

# PostgreSQL

## Windows

1. Ingresar a:

https://www.postgresql.org/download/windows/

2. Descargar PostgreSQL.

3. Ejecutar el instalador.

4. Recordar la contraseña definida para el usuario postgres.

5. Mantener el puerto por defecto:

```text
5432
```

---

## macOS

1. Ingresar a:

https://www.postgresql.org/download/macosx/

2. Descargar PostgreSQL.

3. Ejecutar el instalador.

4. Completar la configuración.
